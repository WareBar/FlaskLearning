# Flask Learning Journey

A personal collection of Flask concepts, experiments, and mini-projects documenting my learning journey. This repository reflects my progress from basic routing to more advanced backend patterns and integrations.

## 📌 About
This repo is not a step-by-step guide, but a hands-on record of what I’ve explored while studying Flask. It serves as both a reference for myself and a showcase of my growth as a developer.

## 🧠 What’s Inside
- **Core Concepts** – Routing, request handling, and Jinja2 templating  
- **Architecture Styles** – Function-based and class-based views  
- **Forms & Input** – Handling user data and validation  
- **Database Integration** – SQLAlchemy and migrations  
- **Authentication** – Sessions and user management  
- **API Development** – RESTful patterns and JSON responses  

## 🚀 Purpose
- Reinforce my understanding through practice  
- Experiment with different Flask patterns  
- Track my progress over time  
- Build a reference for future projects  

## ⚙️ Setup
```bash
git clone <repo-url>
cd <repo-folder>

python -m venv venv
source venv/bin/activate  # or venv\Scripts\activate (Windows)

pip install -r requirements.txt
flask run
```
