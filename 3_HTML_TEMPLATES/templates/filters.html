Filters

Filters are similar to function, you put it beside the text and the filters will be applied

{{ text|upper }}
"upper" filters = make all the letter in uppercase

{{ text|title }}
"title" filters = make the first letter of each word uppercase

{{ text|replace("l", "L") }}
"replace" filters = replaces "l" letters from the text with "L"

{{ text|reverse_string }}
"reverse_string" filters = custom filters that reverses the string
